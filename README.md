# 🐢 slow-primes 🔢

⚡ A deliberately slow prime-summation function, useful for benchmarking and optimization exercises. 🧮

## 🚀 Usage

```bash
📦 npm install
🏃 npm run bench
```

✨ `sumPrimes(n)` finds all primes from 2 to n+1 and returns their sum. 🔍

⚠️ The implementation is intentionally inefficient! 🐌

### Features 🌟
- 🔢 Prime number detection
- ➕ Prime summation
- 🎯 Perfect for benchmarking
- 🧪 Great for optimization exercises
- 💯 Gloriously slow! 🚫⚡
